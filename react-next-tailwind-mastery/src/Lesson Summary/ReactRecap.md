Component: reusable function that returns UI.
Props: read-only information passed from parent to child.
State: React memory for values that change.
Events: user actions such as clicks and typing.
Handlers: functions that respond to events.
Controlled input: React state controls the input value.
Derived value: calculated from existing state, props, or data.
Conditional rendering: current data decides what UI appears.
Lists and keys: map() renders arrays; keys identify items.
Lifting state: shared state belongs in the closest common parent.

_React takes data and state, runs component functions, and produces the correct UI. Events update state, state causes re-rendering, and props carry information downward._
